# KUMAGateGames 8Bit ホームページ Ver.6

前バージョンのファンタジー8Bitデザインを維持しながら、Googleドキュメント「KUMAGateGamesへようこそ！」の文面を実際の各HTMLページへ反映しました。

## ページ
- index.html — ホーム。ビジュアルと各ページへの導線
- about.html — コミュニティ紹介全文、ロール6種類の詳細
- games.html — シーズン制・企画提案・ゲーム募集の説明
- archive.html — シーズンアーカイブ（未開催情報は掲載しない）
- rules.html — ポータルルール全文
- entry.html — 参加の流れとエントリー規定
- support.html — 支援方針とサステイナー詳細（会計報告なし）

## 編集時の注意

## 公開方法
GitHub Pagesにリポジトリルートのファイル一式を配置します。独自ドメイン kumagate.games のDNS設定とPagesのカスタムドメイン設定は別途必要です。

## Ver.9 ホームを完成イメージ準拠の一枚絵に（2026-11）
- PC（横長画面）：横長の一枚絵 `assets/home-stage-wide.webp`（2560×1080、中央1920×1080が完成イメージ）を高さいっぱいに表示し、スクロールなし。メニュー・案内カード・アーカイブ・参加ボタンは絵の上の透明リンク、ゲームカードとXの投稿だけHTMLで重ねています。
- 位置は `index.html` の `--x/--y/--w/--h`（中央部分を1672×941とした座標）で指定。絵を差し替える時は同じ構図なら座標はそのままで使えます。
- 画面が16:9より横長の時は、描き足した左右の景色が見えます（21:9まで対応）。
- スマホ・縦長画面は同じHTMLを縦に並べた表示（`home-hero.webp` と見出しリボン画像を使用）。
- Xのタイムラインが読み込めた場合は絵の投稿部分に重ねて表示。読み込めない時は絵の紹介文が見えます。
- 文字のフォントは M PLUS Rounded 1c（Google Fonts）。
- 旧ホーム用の画像（`pixel-hero.webp` など）は削除せず残しています。
